# 拼好家 · 运营创作中心 — 设计规范 v2.0

> **依据**：从已锁定的 `today-workbench-v2.html` 逐项提取，作为后续页面（灵感雷达 / 内容计划 / 数据复盘 / 账号矩阵 / 知识资产）统一的视觉与结构契约。
> **基准视觉**：Framer 极简 —— 纯黑画布 `#000000` + Framer Blue `#0099ff` 单一强调色。
> **主题**：基准之上另有 4 套衍生主题（毛玻璃 / Fluent 蓝灰 / Bento / 复古杂质），全部经 `:root[data-theme=…]` 覆盖实现，本规范以基准为准。

---

## 0. 一句话设计方向

深色画布 + 单一高饱和强调色 + 胶囊按钮 + 细边框卡片 + mono 等宽数字，**密度适中的运营仪表盘**。一切装饰让位于数据密度；交互状态克制（hover 变亮、active 下压 1px）。

### 1.2 色彩角色（语义速查）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#000000` | 页面画布 |
| `--surface` | `#090909` | 卡片 / 侧边栏 / 输入底色 |
| `--fg` | `#ffffff` | 主文本 |
| `--fg-2` | `#a6a6a6` | 次文本（lead） |
| `--muted` | `rgba(255,255,255,.6)` | 弱文本 / 元信息 |
| `--meta` | `rgba(255,255,255,.4)` | 占位符 / 注释 / 禁用 |
| `--border` | `rgba(0,153,255,.15)` | 卡片描边（带蓝调） |
| `--border-soft` | `rgba(255,255,255,.06)` | 细分隔线 / 行分隔 |
| `--accent` | `#0099ff` | Framer Blue，唯一强调色 |
| `--accent-hover / --accent-active` | `color-mix(accent, black 8% / 14%)` | 按钮交互态 |
| `--success` | `#16a34a` | 增长 / 成功 |
| `--warn` | `#eab308` | 提醒 |
| `--danger` | `#dc2626` | 下降 / 删除 / 必做 |

**强调色预算**：accent 每屏最多出现 2 处主强调（默认 = eyebrow 标签 + 一个主 CTA）；其余只用做 hover/focus/选中态与 9 色语义圆点。不要把整屏刷蓝。

| `--c2 #F97316` | 主号-抖音 | `--c7 #8B5CF6` | 三号-小红书 |

### 1.4 字体

| 角色 | 栈 | 用途 |
|---|---|---|
| Display | GT Walsheim（Framer Medium） | 标题 h1/h2/h3、大数字 |
| Body | Inter Variable | 正文、按钮、标签 |
| Mono | Azeret Mono | 数字 `.num`、eyebrow、meta、百分比、日期 |

- 标题字重：h1/h2 → 700（默认），h3 → 600；字号 `--fs-h1 clamp(30,4vw,46)`、`--fs-h2 clamp(22,2.6vw,30)`、`--fs-h3 17px`。
- 行高随字号收紧：h1 1.04、h2 1.1、h3 1.3、body 1.55。字距：h1 -0.05em、h2 -0.02em、h3 -0.005em。
- eyebrow：11px mono、0.14em 字距、大写、accent 色。
- 所有可比较的数字加 `.num`（mono + `tabular-nums`）。

### 1.5 间距 / 圆角 / 阴影 / 动效

- **间距刻度**：6 / 10 / 16 / 24 / 36 / 56（gap-xs…gap-2xl）。
- **gutter 规则**：容器左右 `padding-inline = --gutter (clamp(16,4vw,28)px)`；每个 section 上下 `padding-block = calc(var(--gutter) / 2)`。**左右与上下间距数值同源、近似对等**，模块间不画分割线，纯留白。
- **圆角**：按钮/输入 `--radius-pill`（胶囊）；卡片 `--radius-lg 20px`；小容器 `--radius-sm 8px`；`.btn-icon` 圆形。
- **阴影**：卡片 `--elev-raised`（顶白 + 深落影双层）；选中环 `--elev-ring`；焦点 `--focus-ring`（accent 30% 3px）。
- **动效**：`--motion-fast 150ms` / `--motion-base 200ms`，缓动 `cubic-bezier(.2,0,0,1)`；按钮 `:active` 下压 `translateY(1px)`（`transition: transform 0.05s`）。

## 2. 布局系统

### 2.1 页面外壳

```
.app-shell (grid: 248px 1fr, min-height 100vh)
├── aside.sidebar   ← 粘性固定左侧边栏
│   ├── .logo            "拼好家 · 运营创作中心"

│   ├── .theme-switch    5 主题切换器（radiogroup）

│   └── .side-foot       版本号 + 数据占位说明
└── .app-main
    └── main#content     各 .section > .container
        └── footer.pagefoot
```

- 侧边栏 248px，`position:sticky; top:0; height:100vh`，`border-right:1px solid var(--border-soft)`。
- `.app-main .container { max-width:none }`（主区满宽，仅留 gutter）。
- **6 项导航固定**：今日工作台 / 灵感雷达 / 内容计划 / 数据复盘 / 账号矩阵 / 知识资产；当前页 `a.on`（浅底 + 左侧 2px accent 竖条）。

### 2.2 栅格原语

| 类 | 规则 |
|---|---|
| `.grid-2` / `.grid-3` | `repeat(2/3, 1fr)`，gap `--gap-lg` |
| `.grid-4` | `repeat(4, 1fr)`，gap `--gap-md` |
| `.grid-1-2` | `1fr 2fr` |
| `.grid-2-1` | `2fr 1fr`，`align-items:start` |
| `.stack` | flex 纵列，子项 `margin-top: --gap-md` |
| `.row` / `.row-between` | flex 横排 / 两端对齐 |

### 2.3 断点

| 断点 | 行为 |
|---|---|
| ≤1100px | `.grid-4` 收为 2 列 |
| ≤920px | 所有 grid 收为 1 列；`.app-shell` 单列；侧边栏折叠为顶部横条（导航横向滚动、CTA 收窄、`.side-foot` 隐藏、主题切换器收为色块圆点行） |

### 2.4 等高行模式

同一行左右卡片高度必须一致，**以主卡片为基准**：

- 主卡片负责高度 → 伙伴卡片 `overflow-y:auto; min-height:0` 内部滚动。
- 基准写法见基准文件 `[data-od-id="todo-pipeline"] .card { height:440px }` 与 `[data-od-id="perf-calendar"]` 三栏结构（`grid-template-columns:1fr 2fr` + 左列 `grid-template-rows:1fr 2fr`）。

## 3. 组件规范

### 3.1 按钮（胶囊体系）

| 变体 | 常态 | hover | 说明 |
|---|---|---|---|
| `.btn-primary` | 白底黑字 | 变 accent 蓝底白字 | 主 CTA，一页一个 |
| `.btn-secondary` | `--btn2-bg` 半透明 | 亮一档 `--btn2-bg-h` | 次级操作 |
| `.btn-ghost` | 透明、muted | 文字变 accent | 页内链接/切换 |
| `.btn-icon` | 32×32 圆形 ghost | — | 图标按钮，必带 `aria-label` |
| `.btn.on` | `--on-bg` 浅底 + 描边 | — | 视图切换的选中态（必须可区分） |

通用：`padding:10px 18px`、`--radius-pill`、`.btn-arrow` 后缀 `→` 且 hover 右移 3px。所有按钮 `:active { transform:translateY(1px) }`。

### 3.2 卡片

- `.card`：`--surface` 底、`1px var(--border)` 描边、`--radius-lg`、22px 内边距、`--elev-raised`。
- `.card-hd`：标题（h3，17px）+ 右侧操作区，`space-between`，下间距 `--gap-md`。
- `.card-flat`：无底无边框，用于纯布局容器。

### 3.3 文本元素

- `.eyebrow`：mono 11px、大写、accent —— 每个模块标题上方的小标签。
- `.meta`：mono 12px、muted —— 时间戳、来源、说明。
- `.num`：mono + tabular-nums —— 一切数字。
- `.lead`：15px、fg-2，最多 60ch。

### 3.4 指标卡 `.metric`

`--surface` 底 + `--border` 描边 + 圆角 + `padding:16px 18px`。结构：`.k`（12px muted 标签）→ `.v`（display 大数字 `clamp(24,2.4vw,30)`）→ `.d`（12px muted 说明，可内嵌 `.trend.up/down/flat` + ↑/↓/→）。

### 3.5 进度条 `.progress`

6px 高、999px 圆角、`--track-bg` 底槽；`> i` 填充条，默认 `--fg-2` 灰，强调场景改 `background:var(--accent)`（如本周进度大模块，10px 高）。

### 3.6 内容日历

- `.cal-head` / `.cal-grid`：`repeat(7,1fr)`，gap 4px；`.cal-cell` min-height 58px、`--radius-sm`、`--border-soft` 描边，竖向 flex（日号 `.dnum` + 发布圆点 `.dots` + 备注旗 `◆`）。
- 状态：`.off`（邻月，opacity .3）/ `.today`（accent 描边 + focus-ring 辉光）/ `.sel`（白描边）。
- 发布圆点：7px 圆点，用 `--c1..--c9`；备注存在显示 `◆` 旗标。
- `.cal-legend`：9 色图例（`<i>` 8px 圆点 + 标签）。
- `.day-detail`：选日后下方详情——发布列表（圆点 + 标题 + 账号标签）+ 备注增删（input + 添加按钮 + 逐条删除按钮）。
- 视图切换：月 / 周按钮用 `.btn.on` 标选中态；顶部 `‹ 2026年8月 ›` 翻月，`aria-label` 上/下个月。
- 无障碍：每个 `.cal-cell` 带完整 `aria-label="YYYY年M月D日"`。

### 3.7 待办 `.todo-group` / `.todo-item`

按优先级分组（组头：8px 圆点 + 12px muted 标签）。每项：标题 13px + 来源 11px muted + 右侧两个胶囊微按钮（`完成` hover 变 success / `推迟`）。完成/推迟后 toast 出现并提供 `撤销`。

### 3.8 流水线 `.pipe-item`

标题 + 时间（`.p-top`）→ 账号标签 `.tag-acc`（7px 圆点 + 名）+ 阶段说明 → `.progress` + 百分比。行间 `--border-soft` 分隔。列表可整体 `overflow-y:auto`（等高行伙伴卡）。

### 3.9 表现速览 `.perf-item`

排名 `.rank`（mono，第 1/2 名用 `--c3/--c2` 着色）+ 标题（单行省略）+ 标记 `.perf-flag.hot`（爆款，`--c3`）/ `.perf-flag.flop`（低于均值，danger）。副行 11px muted：播放 + 互动率。

### 3.10 灵感/日志行 `.inspo-row`

`grid: 140px 1fr auto`，时间戳 + 标题 + 来源账号，行间分隔。用于灵感速递、对标信号、活动日志。

### 3.11 输入 `.input` / `.textarea`

`--surface` 底、`--border-soft` 描边、胶囊圆角、13px；`:focus` 去 outline 换 accent 描边 + `--focus-ring`；placeholder 用 `--meta`。

### 3.12 使用步骤 `.use-steps`

命令条内的横向 4 步流程：`.use-steps-row` `grid: 1fr auto 1fr auto 1fr auto 1fr`；每步卡片（`--surface` + `--elev-ring`）= mono 编号（accent）+ 标题 + 说明；SVG 箭头连接，≤920px 单列堆叠、箭头转 90°。

### 3.13 Toast

`position:fixed` 底部居中胶囊，`role="status" aria-live="polite"`，内含消息 + 可选 `撤销` 按钮（accent 文字）。显示 3200ms，`.show` 控制显隐（translateY 16→0）。

## 4. 主题系统（5 套）

| 主题 | 机制 | 关键差异 |
|---|---|---|
| `framer`（默认） | 基准 `:root` | 纯黑 + Framer Blue 胶囊 |
| `glass`（毛玻璃） | `:root[data-theme="glass"]` 覆盖语义令牌 + body 渐变环境光 + 卡片 `backdrop-filter: blur(24px) saturate(160%)` | 圆角上调 10/16/24，白描边 |
| `fluent`（蓝灰） | 令牌覆盖 | 浅色反转（`#f3f5f8`），Segoe 字体，圆角 4/6/8、按钮变矩形，9 色加深去饱和 |
| `bento`（便当盒） | 布局覆盖 | `#content` 变 12 列网格去分隔线，卡片跨列错落（日历 4/8、待办流水线 4/8），≤920px 折叠单列 |
| `retro`（复古杂质） | 令牌覆盖 + `body::after` 噪点层 | 奶油纸底 + 衬线（Iowan/Georgia）+ 烧橙强调 + 莫兰迪 9 色 + SVG 颗粒覆盖层 |

- **切换器**：侧边栏 `.theme-switch`（`role=radiogroup`），按钮 `[data-theme-btn]`，选中 `aria-checked=true`，`localStorage` 键 `phj-workbench-theme`，加载时 `applyTheme(saved)`。
- **新页面必须保留**切换器 + `applyTheme/initTheme` 逻辑，保证与工作台一致、主题能跨页统一。主题块追加在 `<style>` 末尾（组件 CSS 之后），只在 `:root[data-theme=…]` 作用域内覆盖语义令牌或组件规则。

## 5. 交互与状态约定

- 一切可变数据集中在 JS IIFE 顶部（对象/数组常量 + `state`），渲染函数读 state 生成 DOM；事件绑定用「重建后重新 querySelectorAll 绑定」模式（见日历/待办）。
- 破坏性/瞬时操作（完成、推迟、删除、备注）→ toast 反馈，可撤销的提供 `撤销` 按钮。
- 加载类操作（刷新雷达）→ 按钮文案切换"刷新中…" + `disabled`，结束 toast 回报结果。
- 有明确选中态的切换控件（月/周、主题）必须视觉可区分（`.on`）。

---

## 6. 可访问性基线

- `a / button / [tabindex]:focus-visible` → `2px solid var(--accent)` 外描边，offset 2px（`.btn`/`.cal-cell` 3px）。**不允许移除 outline 且不给替代**。
- `prefers-reduced-motion`：全量 `transition/animation-duration:0.01ms`、`scroll-behavior:auto`、按钮 `transform:none`。
- 图标按钮、日历格子必须带 `aria-label`；动态反馈（toast）用 `role=status aria-live=polite`。
- 对比度：主文本白 on 黑远高于 AA；muted/meta 仅用于次要信息。

---

## 7. 文案与内容规则

- 全 UI 简体中文；品牌名（拼好家、Framer、GT Walsheim 等）与技术标识保持原样。
- 模块标题上方用 eyebrow 小标签；数字一律 `.num`。
- 演示/占位数据必须在模块内标注（如「演示数据」「数据为演示占位」）。
- 图标用内联 SVG（stroke 1.5–2，`currentColor`）或 CSS 圆点，**不用 emoji 当特征图标**；正文里一个模块只保留一个主 CTA。
- 数值变化用 `.trend.up/down/flat` + ↑/↓/→，配 `--success/--danger/--muted`。

## 8. 新页面构建配方

### 8.1 骨架（新建 HTML 的固定顺序）

```
<!doctype html><html lang="zh-CN"><head>
  charset + viewport + <title>页面名 · 拼好家</title>
  <style>
    1. :root 令牌块（§1.1 verbatim）
    2. reset & base（box-sizing / body / img / a / button / text-wrap）
    3. focus & reduced-motion 无障碍块（§6）
    4. layout primitives（.container/.section/.stack/.row/grid-* + 断点）
    5. type（h1-h3/.lead/.eyebrow/.meta/.num）
    6. chrome（.app-shell/.sidebar/.app-main/.pagefoot + ≤920 折叠）
    7. buttons（§3.1）
    8. card / metric / progress / 本页组件
    9. 主题块（framer 基准 + glass/fluent/bento/retro，追加于尾部）
  </style>
<body>
  .app-shell > aside.sidebar（6 导航 + 主题切换器 + CTA + 脚注）
        + .app-main > main#content（各 section[data-od-id] > .container）+ footer.pagefoot
  .toast（role=status aria-live=polite）
  <script> IIFE：数据常量 → state → 渲染函数 → 事件绑定 → init
</body></html>
```

### 8.2 各页 section 建议（沿用工作台节奏：命令条头 → 核心模块 → 收尾）

- **灵感雷达**：命令条（h1 + 刷新雷达）→ 信号流（`.inspo-row` 列表 + 状态筛选）→ 灵感速递 → 快捷跳转。
- **内容计划**：命令条（h1 + 新建选题 CTA）→ 日历/排期（9 色）→ 流水线全量 → 发布队列。
- **数据复盘**：命令条（h1 + 时间范围切换）→ 4 指标卡 → 趋势（周/月）→ Top3 + 爆款/翻车明细。
- **账号矩阵**：命令条（h1 + 数据刷新）→ 9 账号卡网格（`--c1..--c9` 标识）→ 粉丝趋势对比。
- **知识资产**：命令条 → 分类网格 → 资产列表。

### 8.3 数据层约定

所有演示数据放 IIFE 顶部常量（如 `ACCOUNTS / RELEASES / TODOS / state`），渲染函数不得硬编码业务数据；跨模块复用的账号×平台映射用 `ACCOUNTS`（9 项）统一驱动。
