## 可复用教训
- macOS 默认是 **BSD grep**，不支持基本正则的 `\|`  alternation（GNU grep 才支持）→ 多条件匹配务必用 `grep -E` 或 `grep -nE`，否则返回 0 误判为「代码缺失」。
- 跨分支带单提交用 cherry-pick 比 merge 干净：先 `git diff --quiet B1 B2 -- <files>` 确认基线一致，再 cherry-pick，可避免带入无关提交。
- 额度耗尽时：代码改动已落盘但未提交也安全，额度回来先 `node --check` + grep 核验再 commit，别急着信「0 匹配」。
