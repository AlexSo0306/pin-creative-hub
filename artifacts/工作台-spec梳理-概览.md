## 做了什么

把该仓库的 10 份规格类文档与**已提交的代码**逐项核对，产出两份新文档：

## 三个核心发现

1. **文档声明的成熟度整体失真。** `README-产品总览.md` 把 5 个模块标成「待开发」，实际六个模块前后端全部已实现、有 17 个测试用例覆盖。**缺的不是功能，是真实数据。**
2. **六处引用已失效。** 指向不存在的 `模块PRD-v1.0/` 目录、错误的文件名、已被 SQLite 取代的 `workbench.json`。
3. **协作机制空转。** `docs/AI-COLLAB.md` 的共享开发日志**零条记录**，而 `AGENTS.md` §6 要求每次收工必写——两机 AI 交接机制从未真正跑起来。

## 只存在于代码里的事实（下一个接手人会踩）

- 统一 API 响应契约 `{ ok: true, data }` / `{ ok: false, error }`，任何 spec 都没写
- 前端 hash 路由名与文件名不一致：`#/review` ↔ `pages/data-review.js`
- `content_publish_records` 的唯一约束 `(content_card_id, platform)` **锁死了发布结构**，「一菜三发」在当前模型下无法表达
- `content_performance` **没有任何完播类字段** → 现有模型无法承载留存诊断
- `dashboard_todo_actions` 是日粒度状态，不是任务实体

## 关键决策

- **只加不改**：过期文档加状态标记，不重写正文（重写会丢目标态信息，且无法验证是否引入新失真）
- **规格与代码分离**：6 份 Feature Spec 从代码目录根迁入 `docs/specs/`
- **权威顺序落纸**：代码 > AGENTS.md > as-built > Feature Spec > README，并写死「spec 变更必须回写 as-built」
- **文档任务的验收必须机械可检**：全部用 grep 断言，不靠人眼

## 追加 · 能力栈 ↔ 工作台模块 映射（2026-09-21）

把运营工作区的 A–F 六层能力栈（`artifacts/项目功能蓝图.md`）与工作台六模块做交叉比对，
产出 `pin-creative-hub/docs/specs/capability-module-map.md`。

**核心发现：两者不是同一根轴。**
蓝图按「**能力**」组织（诊断→对标→拆解→改造→验证），工作台按「**东西的状态**」组织
（选题池→脚本库→制作中→已发布→已复盘）。所以缺的不是模块数量，是**「方法」这一维**。

**五层能力的工作台承载**

| 能力层 | 承载 | 缺口 |
|---|---|---|
| A 数据诊断 | 数据复盘 + 今日工作台 | 🔴 缺完播字段 → 漏斗第二环算不出 |
| B 对标研究 | 灵感雷达（137 条） | 🟡 拆片结论无处沉淀 |
| C 内容拆解 | **无承载** | 🔴 六拍模板只活在一份 md 里 |
| D 改造执行 | 内容计划 | 🟡 一菜三发装不下（唯一约束） |
| E 验证闭环 | review_conclusions | 🔴 无假设/样本/阈值 → 验证不了 |

**最要紧的一处**：A 的缺口和 E 的缺口是**同一件事**——漏斗第二环（完播留存）算不出来，
而验证修复效果的载体也不存在。**发现问题的地方和验证修复的地方，同时不存在。**
而卡点恰恰在这一环（5s 完播 27% vs 健康线 60%）。

**建议补的三处（按性价比）**：① 完播字段（S，最小改动最大收益）② 验证/实验实体（M–L，最该加的模块）
③ 灵感雷达「可抄动作」字段（S–M）。

> 原第 3 条「内容计划加版本维度」**已撤销**——业务规则于 2026-09-21 改为**一菜一发**，
> `UNIQUE(content_card_id, platform)` 与该规则完全一致，无需改动。

**一菜一发对验证闭环的正面影响**：三发时期同菜多版本互相稀释（汉堡批次 B 7,504→5,044→2,404）；
一菜一发后**一条内容 = 一个变量**，5s 完播可干净归因 → 「连发 5–7 条看 5s 完播破 50%」
这个实验**第一次变得可执行**。代价是版本间对比消失（只能跨菜比较）。

**随之而来的决策**：发哪个版本？数据说正片扛涨粉/播放（均增粉 12.3、57% 涨粉、播放均值 8,062），
快剪扛主页访问（1.06%）。但主页→关注 19.2% 已健康 → 引流不是瓶颈 → **推荐发正片**。

**与 React 迁移的优先级**：迁移换的是"怎么盖"，上面 3 条换的是"盖什么"。
建议**至少先把完播字段加上**——纯数据层改动，与框架无关，迁移前后都不浪费。
