# 账号定位诊断清单 · 抖音美食号（情侣做饭）

> 适用账号：苏师傅爱做饭｜双人治愈晚餐
> 用途：涨粉停滞期，逐条自检定位是否成立
> 诊断顺序：先看数据卡点（漏斗），再诊断定位 4 维度

---

## 第 0 步：先判断涨粉卡在漏斗哪一环

| 环节 | 抖音后台看什么 | 健康参考 | 卡住 = 什么问题 |
|---|---|---|---|
| ① 播放量 | 近 20 条播放中位数 | 均值 3000-5000+ | 选题/封面/钩子没进流量池，是内容问题不是定位问题 |
| ② 完播率 | 视频完播率、3s 完播 | 整体 >30%，3s >60% | 节奏问题，开头钩子失效 |
| ③ 主页访问 | 创作者中心-数据中心 | 播放→主页点击 >5% | 单条没引发"这人是谁"的好奇 |
| ④ 关注转化 | 主页点击→关注率 | >10% | **定位/人设记忆点问题（本文重点）** |

> 口诀：卡 1-2 环改内容，卡 3-4 环改定位。
> 如果播放不错但涨粉低 → 你的问题几乎肯定在 ③④。

---

## 维度 A：人设辨识度（用户 3 秒能记住你什么）

**自检问题**
- [ ] 不看内容，只看主页（头像+昵称+简介+背景），能说出"这是对情侣在做饭"吗？
- [ ] 口播/字幕有没有专属口头禅或固定开场白（如"BB 吃饭喽"）？
- [ ] 你的画面里"情侣感"靠什么传达？（双人同框？双份餐具？对话？）

**数据佐证**
- 评论里高频词是"好治愈""羡慕你们"，还是"求教程""怎么做"？
- 女主若不出镜/少出镜，情侣人设是否只靠文案和双碗镜头撑着？

**自查结论：_____ 分（1-5）**

---

## 维度 B：内容一致性（算法和用户能否识别你是"垂直账号"）

**自检问题**
- [ ] 近 20 条选题是否都在"双人晚餐/治愈"这条线上？有没有混发教程、探店、单人餐？
- [ ] 封面是否统一版式（同字体/同构图/右下角"苏师傅爱做饭"落款）？
- [ ] 开场结构是否稳定（3 秒双碗俯拍 + CPB 菜单仪式感）？
- [ ] 标题是否遵守 16-22 字 + 数字反差规则，没有乱用感叹号/诱导词？

**自查结论：_____ 分（1-5）**

---

## 维度 C：人群匹配（看的人 ≠ 关注的人 ≠ 你想要的人）

**自查清单**
- [ ] 抖音粉丝画像：性别、年龄、城市分布是什么？
- [ ] 美食教程观众（来学菜，女生偏多）和"情侣治愈"观众（来嗑糖）是两拨人——你现在的流量主力是哪拨？
- [ ] 数据好的视频，靠的是"菜本身"（做法/摆盘）还是"关系"（情侣互动）？
- [ ] 你未来要接的商单/变现方向，需要哪拨人？现在涨的粉是那拨吗？

> 关键判断：如果数据好的是纯美食选题、涨粉慢的是人设向选题，说明
> "情侣做饭"目前只有定位口号，没有成为内容竞争力。

**自查结论：_____ 分（1-5）**

---

## 维度 D：记忆点 · 非你不可（核心竞争力测试）

**灵魂拷问（定位成立的唯一标准）**
- [ ] 把"情侣"元素全部去掉，你的视频在同类美食号里还成立吗？
  - 还成立 = 观众为"菜"而来 → 你的真实定位其实是"美食教程"，情侣只是包装
  - 不成立 = 观众为"你们"而来 → 情侣人设才是护城河，要加大它的含量
- [ ] 观众关注你，是因为"这道菜"，还是因为"这对人"？翻关注你时的动机评论判断
- [ ] 同类账号里，"双人治愈晚餐"至少有几十个在做——你和他们的差异点写得出 1 句话吗？

**一句话定位公式（写不出来 = 定位还没成型）**
> 我是（_____的广州情侣），在（每晚下班后）做（双人治愈晚餐），
> 让你（想学/想代入/想被治愈）。和别的美食号不同，我（______）。

**自查结论：_____ 分（1-5）**

## 汇总诊断表

| 维度 | 分数(1-5) | 病根判断 | 动作优先级 |
|---|---|---|---|
| A 人设辨识度 | | 记忆点弱 → 主页重做 + 固定口头禅 | |
| B 内容一致性 | | 号太杂 → 选题收窄到一条线 | |
| C 人群匹配 | | 流量错位 → 明确目标粉并只服务他们 | |
| D 记忆点 | | 情侣只是包装 → 加深关系含量 | |

**优先级排序：先补最短板的 1 项，连发 10 条验证，再看涨粉变化。**

---

## 一句话总结

> 涨粉上不去，先别急着换赛道。
> 把 20 条视频拉出来：数据好的选题长什么样、数据差的长什么样，
> 数据会告诉你观众到底为什么关注你——那才是你真正的定位。
