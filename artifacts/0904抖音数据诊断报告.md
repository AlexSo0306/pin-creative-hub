## 一、核心结论（先看这个）

> **涨粉停滞 ≠ 定位错误。漏斗卡在第二环「留存」：前 5 秒留不住人 → 完播率崩 → 算法停止推流 → 播放天花板锁死。**  
> 你的"主页→关注 19.2%"是健康水平的近 2 倍——只要把人留住，他们非常愿意关注你。问题根本不在定位。

## 三、留存为什么崩？均播 6.6s 意味着什么

账号视频多为 50-60s（47 条 1min 视频），但观众平均只看 **6.6 秒** —— 即 **90% 的成片没人看到**。

- **2 秒跳出率 43%**：接近一半的人第一眼就划走 → **封面 + 第一帧 + 前 2 秒钩子全线失效**
- **5 秒完播率 27%**：剩下的人里又走掉一大半
- 能活过 5 秒的人极少 → 完播率中位只有 3.68% → 算法判定"内容留不住人"，不给下一级流量池

**推论**：你现在起量的 6 条破万作品，大概率靠"选题本身强"（梅渍小番茄/京葱鸡胸肉/餐厅复刻）硬顶过初始流量池，而不是靠完播驱动。完播不修复，破万就是天花板。

## 五、可执行的修复动作（按优先级）

### P0 · 修 3 秒钩子（1-2 周内，全部新视频执行）

- 前 2 秒跳出 43% → 封面第一帧必须出现"成品 + 反差钩子"（如"这锅38，餐厅卖128"），禁止以备料/厨房空镜开场
- 参考规则总览：3 秒双碗/双份俯拍，但**必须叠加文字钩子**，纯画面无信息量是留不住人的
- 自查：新视频 5s完播率 <60% 即视为废片标准，立即复盘开头

### P1 · 压缩节奏，尊重 6.6s 现实

- 1min 视频按"15s 一个信息爆点"切：3s钩子→12s第一道菜关键动作→25s成品反差→40s步骤快闪→50s BB收尾
- 把"教程价值"前置：观众平均只给 6.6 秒，最值钱的配方信息要在 10s 内给到

### P2 · 放大数据验证过的选题方向

- 餐厅复刻 + 价格反差 是被 6 条破万作品反复验证的引擎，占比提到 50%+
- "情侣"作为差异化记忆点保留在片尾/封面落款，**不承担拉流任务**（数据证明它拉不动）

### P3 · 关注转化已健康，别动它

- 主页→关注 19.2% 远高于健康线 → 主页装修/简介不要大改，保持

## 八、标杆作品逐帧拆解（5s 完播最高：番茄红酒炖牛肋条正片）

> 完整报告：`artifacts/逐帧拆解-番茄红酒炖牛肋条正片.md`

**核心发现**：这条视频的"开头"不是普通的 3 秒钩子，而是**一段剪辑紧密的 6 秒微预告片**——在 0-5.83 秒里塞了 **6 个快速剪辑镜头**，每个镜头都打字幕/视觉爆点。

| 时间 | 镜头 | 字幕 |
|---|---|---|
| 0.0s | ①封面 — CPB菜单 + 成品 + 主标题 | "番茄红酒炖牛肋条 / 90分钟复刻餐厅味道" |
| 0.17s | ②爆点 — 砂锅开盖沸腾 | **"怎么用28块钱做出"** |
| 1.83s | ③价值 — 装盘瞬间 | **"外面卖88的"** |
| 2.83s | ④诚意 — 食材全景摆台 | "番茄红酒炖牛肋条" |
| 4.83s | ⑤人设 — 双人份上桌 | "番茄红酒炖牛肋条" |
| 5.83s | ⑥教程开始 — 切牛肋条 | **"新鲜的牛肉不用焯水"** |

**为什么 5s 完播最高（40.2% vs 账号均值 27%）**：
1. 每个 1 秒都给观众一个"留下来的理由"
2. 价格反差字幕（28 vs 88）作为必备钩子
3. 情侣镜头前置（4.83s 出现双人份），让人设瞬间兑现
4. 教程不晚于 6 秒开始——钩子全部兑现完才进教程

**修复路径**：把"6 秒预告片 + 教程主体 + 情侣收尾"的三段结构**作为模板套用到其他视频**。每个新视频先剪 6 秒预告片，价格反差字幕必备，情侣镜头必前置，教程开始不晚于 6 秒。

抽帧产物保存于：`artifacts/逐帧拆解/番茄红酒炖牛肋条-正片/`

# 附录 · 「一菜三发」打法验证（基于用户手工标记版 2026-09-04）

> 数据源：`0904 作品列表导出-作品标记.xlsx`（32 条公开作品，用户手工标记体裁）  
> 版本定义：正片 = 1min 左右教程（15条）｜开头快剪 = 纯享快剪 4-8s（9条）｜情侣快剪 = 成品展示 <10s「今天给TA做了…」（8条）

## 1. 三版本战力对比（核心结论）

| 指标               | 正片 (15)           | 开头快剪 (9)      | 情侣快剪 (8)      |
| ---------------- | ----------------- | ------------- | ------------- |
| 播放 均值/中位         | **8,062** / 7,772 | 4,916 / 3,964 | 4,680 / 2,829 |
| 播放 合计            | **120,932**       | 44,240        | 37,441        |
| 完播率 均值           | 4.54%             | 20.46%        | **22.23%**    |
| 5s完播率 均值         | 25.02%            | 25.11%        | **28.73%**    |
| 2s跳出率 均值         | 38.27%            | 37.35%        | **35.04%**    |
| 主页访问率(主页÷播放)     | 0.60%             | 0.59%         | **1.06%**     |
| 粉丝增量 合计          | **185（占57%）**     | 52            | 44            |
| 粉丝增量 单条均值        | **12.3**          | 5.8           | 5.5           |
| 涨粉效率(加总口径 粉增/播放) | **0.153%**        | 0.118%        | 0.118%        |

**版本角色定位**

- **正片 = 涨粉主力**：播放、涨粉总量、单条涨粉、涨粉效率四项第一 → 承担涨粉任务，不能砍
- **情侣快剪 = 主页访问之王**：主页访问率 1.06%，是另两类的 **1.7-2 倍** → "情侣钩子"确实能把人引到主页，首次有正面数据支撑情侣人设；且 5s完播/2s跳出三类中最好
- **开头快剪 = 鸡肋**：主页访问率 0.59% 垫底、涨粉总量最低，仅靠 1 条 1.7 万（京葱鸡胸肉 08-11）撑均值，**剔除爆款后单条均值仅约 3.4k** → 未承担"引流"角色，建议砍掉或改造

## 2. 完播"水分"验证（证实你的直觉）

- 短版完播率 20-22% ≈ 正片 4.5% 的 **4-5 倍** → 账号整体完播率确实被短版拉高，正片真实留存是硬伤
- **但 5s完播三类只有 25-29%（健康线 60%）** → 开头留不住人是全账号通病，**与视频长短无关** → 三发没有解决开头问题，只是把同一道菜榨了三遍

## 3. 同菜多版本：会不会互相抢量？

| 模式     | 例子                                                | 结果        |
| ------ | ------------------------------------------------- | --------- |
| 后发被虹吸  | 徐福烩饭(后发0.23x)、味增汤(0.20x)、益力多猪扒(0.13x)、汉堡批次B(逐条递减) | 首发吃掉大部分流量 |
| 后发反而爆发 | 焖饭情侣版(隔4天3.5x)、汉堡批次A(逐条递增)、打抛饭(后发2x)              | 后发吃到更多    |

**判断**：不是必然抢量——关键在"版本间是否差异化 + 间隔是否足够"。但连续 2-3 天内发同画面内容，整体呈稀释趋势（汉堡批次B 7,504→5,044→2,404 递减就是反例）。

## 4. 打法调整建议

1. **正片扛涨粉**：保持 60-75s 教程，它是账号涨粉发动机
2. **情侣快剪加大投入**：主页访问率 1.7-2 倍是实打实的信号——情侣钩子是你差异化里唯一被数据验证有效的部分
3. **开头快剪砍掉或改造**：目前数据证明它既不带量也不带粉；若要保留，改成"纯享版独立成片"，与正片画面差异化、错开 2-3 天发
4. **核心还是修开头**：三类 5s完播均 25-29%，不突破 50% 生死线，发几个版本都是低效重复
