## 0. 先说结论：你选得对，而且比我上版推的更聪明

我上一版推荐的是**头部人设号**——它们的问题是：过了成长期后，内容重心从"教做菜"转移到"人设日常+种草"，**教程只是包装**。
你选的这批是**以烹饪为内容本体**的号，其中多数还是**万级成长号**。这意味着三件事：

1. **它们还在"被算法验证"的阶段**——能活下来就说明当前的内容结构是抖音此刻认可的，不是吃老本
2. **它们离你不远**——拆头部号学的是"怎么维持"，拆万级号学的是"怎么从万级爬到十万级"，后者才是你现在需要的
3. **你现在看它们，等于在它们身上找"下一条爆款路径"**——等它们涨到几十万，你学到的就过时了

> 一句话：**头部人设号 = 看终点；万级教程号 = 看路径。你要的是路径。**

## 2. 教程号 vs 日常号：你要偷的引擎不同

| 维度 | 日常/人设号（上版推的） | 教程号（你自选的） |
|---|---|---|
| 观众关注理由 | 想"看这对人" | 想"学/收藏这道菜" |
| 核心指标 | 关注率、主页访问 | **收藏率、5s完播、完播** |
| 情侣元素作用 | 内容本体 | 叙事线/记忆点 |
| 涨粉引擎 | 人设驱动 | 菜的价值驱动（复刻/价格/做法） |
| 你该学的 | ❌ 已过你的阶段 | ✅ 正是你缺的 |

**你的账号数据早就证明了你是教程号引擎**（破万作品全是"梅渍小番茄/京葱鸡胸肉/复刻"类），所以对标教程号 = 顺势放大，不再拧巴。

## 3. 万级教程号拆解模板（拿回去逐号填）

每个号抽最近 10 条（别只看爆款，看常态），逐条填：

| 拆解项 | 观察点 | 它怎么做的 | 我能不能抄 |
|---|---|---|---|
| 开头 3 秒 | 成品先出？还是备料？有没有反差钩子？ | | |
| 教程何时开始 | 前 6 秒内？ | | |
| 价格/成本信息 | 有没有"多少钱/复刻餐厅"类字幕？ | | |
| 字幕密度 | 静音能看懂吗？配方是否文字化？ | | |
| 收藏钩子 | 看完为什么想收藏？（步骤/比例/清单） | | |
| CP/人设元素 | 第几秒出现？占全片几成？ | | |
| 时长与节奏 | 多长？几秒一个信息点？ | | |
| 更新频率 | 几天一更？同菜多版本吗？ | | |
| 标题公式 | 归纳它的固定句式 | | |

**判断标准**：把它 10 条里"你愿意完整看完并收藏"的挑出来 → 那就是它当前正在被验证的爆款结构 → 抄结构不抄菜。
