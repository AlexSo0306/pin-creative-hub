## ⑯ 锅宝特效粒子渲染成黑色：补上「引擎缺失的宿主样式契约」（02:35）

### 怎么发现的
换引擎后套件 **25/25 全绿**，但**把截图打开看**，`33 任务完成` 容器右上角
飘着一个 **18×17 的黑块**。套件没报 —— 因为当时根本没有断言盯着特效配色。
→ **「断言通过」不等于「看过了」。**

### 根因（一条被忽略的契约）
mood-mates 引擎**不带样式表**。`core/fx.js` 建图元时**只挂类名、不给 `fill`**：
```js
el('path',    { d: cloudD, class: 'mm-bubble' })   // ← 没有 fill
el('circle',  { r: 1,      class: 'mm-speck'  })
el('ellipse', { cx: -5.2,  class: 'mm-sheen'  })
```
颜色规则写在上游**演示站**的 `site/style.css`（754–760 行），**不在 `core/` 里**。
当初按「只搬引擎、跳过 `site/`」引入 → 漏了 → 图元落到 SVG 默认 `fill:#000`。
→ **「引入一个库」≠「拷贝它的 `core/`」**。类名是宿主必须兑现的**样式契约**，
它可能写在仓库的另一个目录里。搬库前先 grep 类名在整个上游仓库的定义位置。

### ⭐ 新断言第一次跑就暴露自己是空转的
新加断言「特效粒子有配色，没落到黑色兜底」。按纪律做注入对照
（`INJECT_FX_BLACK=1` 强制成黑）复现现场，结果：
```
✓ 特效粒子有配色，没落到黑色兜底 — 黑色 0 / 0 个     ← 绿着，但一个都没查到
✗ 特效粒子确实出现（否则下一条会空转） — 命中 0 个
```
**粒子是瞬态的**：泡泡走完 `travel + hang + pop` 就被移除。
第一版「`setEmotion('33')` → `sleep(1500)` → 点采一次」正好撞在空档上。
→ 改成 `celebrate()` 触发后 **26 次 × 120ms 轮询取峰值**，
并把 **`峰值 > 0` 也写进第二条的条件** —— 集合为空时绝不允许判绿。
→ **通用规则：瞬态动画的断言必须轮询；计数类断言必须配一条「集合非空」的兄弟断言。**
