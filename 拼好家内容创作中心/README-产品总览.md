# 拼好家运营创作中心 — 产品总览

> 最后更新：2026-08-04  
> 当前阶段：MVP 0.1.0  
> 运行形态：本地单机 Web 工作台

---

## 1. 产品定位

一个将 **外部灵感采集 → 内容计划 → 多平台账号运营 → 数据复盘 → 方法沉淀** 集中在一起的本地自媒体运营工作台。

**目标用户**：同时运营小红书、抖音、视频号的自媒体负责人、内容策划和运营人员。

**当前核心价值**：建立一个可检索、可持久化的对标内容资料库，并为完整运营闭环提供产品框架。

## 3. 运营闭环架构

```
选题空间（数据隔离）
    │
    ├── 灵感雷达 ──→ 内容计划 ──→ 账号矩阵（选择发布账号）
    │      ↑                          │
    │      │                          ↓
    │      │                    内容发布（外部平台）
    │      │                          │
    │      │                          ↓
    │      └──────── 数据复盘 ←── 手动录入表现数据
    │                     │
    │                     ↓
    └────────────── 知识资产（沉淀可复用方法）
                         │
                         └──→ 内容计划（下次排期引用）
```

**当前断点**：只有"灵感雷达 → 外部对标研究"形成了真实数据能力，其余环节的数据链路尚未打通。

## 5. 建设优先级

### P0：打通最小真实闭环
1. **真实内容计划** — 新增/编辑/删除/拖动内容卡，持久化存储
2. **灵感转选题** — 对标作品一键生成选题卡
3. **发布与复盘记录** — 手动录入平台表现数据，自动计算衍生指标
4. **真实今日工作台** — 任务和排期由内容计划自动生成

> P0 验收标准：用户可以在不修改代码和 JSON 的情况下，完成一条真实内容从对标灵感、选题、排期、发布到复盘的全过程。

### P1：提高资料库维护效率
- 选题空间创建/配置
- 对标创作者和平台账号管理页面
- 手动作品录入表单 + CSV 批量导入
- 账号矩阵改为真实可维护数据
- 知识资产改为可编辑文档

### P2：规模化与协作
- 数据导入/导出/备份
- 多用户、云端同步（当前产品边界外）
- AI 辅助选题聚类、脚本初稿、复盘摘要

## 8. 产品成功指标（上线后观察）

| 指标 | 含义 |
|------|------|
| 灵感转选题率 | 加入选题池的灵感数 / 已标记灵感数 |
| 选题发布率 | 已发布内容数 / 已排期内容数 |
| 复盘完成率 | 已复盘内容数 / 发布满规定天数的内容数 |
| 方法复用率 | 使用知识资产模板的内容数 / 总发布内容数 |
