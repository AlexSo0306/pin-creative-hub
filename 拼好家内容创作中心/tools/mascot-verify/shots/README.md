## 对拍图的特殊说明（⚠️ 生成脚本暂不在本仓库）

`锅宝-与原版并排对拍.png` 由 `/tmp/grok-ref/side-by-side.mjs` +
`shoot-side-by-side.mjs` 生成，**这两个脚本目前只存在于 `/tmp`，未入库**。
它依赖一份**外部下载**的原版几何数据：

```
/tmp/grok-ref/grok-icon-study-main/replica/geometry-data.js   ← 原版 25 个眼形的 48 点环
```

→ 也就是说：**这张图现在无法从本仓库复现**。这是已知的债，不是「已经复现过所以没问题」。
想复现需要：① 取回上面那份 geometry 数据；② 把两个脚本搬进 `tools/mascot-verify/`。
在此之前，**请把这张图当作「某次对拍的留档」而不是「可回归的基准」** ——
形状是否合规，以 `check-eye-shapes.mjs` 的数字为准（它读的是真 `guobao.js`）。

`side-by-side.mjs` 里的**形状表不自己抄一份**，而是 `execFileSync` 问
`check-eye-shapes.mjs --json` 要 —— 这条纪律别丢，否则表会与真源漂移。
