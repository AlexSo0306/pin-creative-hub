## 1. Problem Statement

v1.0 的账号矩阵展示了三个示例账号卡片，但数据写死在前端代码里，不能新增、编辑或删除。自媒体运营者实际运营多个方向不同的账号（如"苏师傅爱做饭"做美食二人食、"英爱家38平"做小户型家居、"游泳健身了解一下"做健身内容），每个账号会差异化发布到抖音、小红书、视频号三个平台。账号信息是内容计划的"账号切换"、今日工作台的"9 色日历"的数据源头，如果账号不能维护，下游模块全部无法落地。

**v2.0 要解决的核心问题**：让账号矩阵从"静态示例"升级为"自有账号管理中心"——支持账号的创建、编辑、停用和删除，每个账号管理三个平台的发布信息，为内容计划和今日工作台提供动态账号数据源。

**真实账号（当前）**：

| 账号 | 内容方向 | 平台 |
|------|---------|------|
| 苏师傅爱做饭 | 美食 / 二人食晚餐 | 抖音 + 小红书 + 视频号 |
| 英爱家38平 | 家居 / 小户型改造 | 抖音 + 小红书 + 视频号 |
| 游泳健身了解一下 | 健身 / 训练日常 | 抖音 + 小红书 + 视频号 |

**注意**：这三个账号是临时的，随时可能新增、改名或停用。账号必须可在设置中自由维护，不能硬编码。

**不解决的成本**：账号信息散落各处，内容计划无法按账号筛选，今日工作台日历无法用颜色区分"账号×平台"，运营者无法在工作台内统一管理账号定位和发布策略。

## 2. Goals

| # | 目标 | 衡量方式 |
|---|------|---------|
| G1 | 用户能创建、编辑、停用和删除自有账号 | 账号 CRUD 操作全部可持久化 |
| G2 | 每个账号能维护三个平台的发布信息（用户名、链接、状态） | 平台信息独立编辑 |
| G3 | 账号列表成为内容计划和今日工作台的动态数据源 | 其他模块实时读取，不硬编码 |
| G4 | 每个账号有独立颜色，供看板和日历标记使用 | 颜色在账号矩阵中可分配和修改 |
| G5 | 内容计划的账号切换栏、卡片账号标记自动同步账号矩阵数据 | 新增/停用账号后同步生效 |

---

## 3. Non-Goals

| # | 不做什么 | 原因 |
|---|---------|------|
| N1 | 不管理对标创作者账号 | 对标创作者在灵感雷达模块管理 |
| N2 | 不读取平台真实粉丝数和互动数据 | 需平台 API，产品边界外 |
| N3 | 不实现账号间的对比分析图表 | P2 规划 |
| N4 | 不管理登录凭据和发布权限 | 产品不直接发布内容到平台 |
| N5 | 不管理账号矩阵的历史版本（账号改名记录） | 覆盖更新即可，历史追踪 P2 |

## 4. User Stories

### 4.1 账号管理

| 优先级 | 用户故事 |
|--------|---------|
| P0 | 作为自媒体运营，我希望能创建一个新账号（如"英爱家38平"），填写名称、内容方向和运营状态，以便拓展新的运营方向。 |
| P0 | 作为自媒体运营，我希望能编辑账号的基本信息（改名、改方向、改状态），以便账号定位调整时同步更新。 |
| P0 | 作为自媒体运营，我希望能停用一个账号，以便账号暂停运营时不占用看板空间，但历史内容记录保留。 |
| P0 | 作为自媒体运营，我希望能删除一个账号，以便清理误建的账号。（删除需二次确认） |
| P1 | 作为自媒体运营，我希望能看到每个账号的内容方向标签（美食/家居/健身），以便快速区分不同账号的定位。 |

### 4.2 平台信息管理

| 优先级 | 用户故事 |
|--------|---------|
| P0 | 作为自媒体运营，我希望能为每个账号维护抖音、小红书、视频号三个平台的发布信息（平台用户名、主页链接、发布状态），以便账号详情完整。 |
| P0 | 作为自媒体运营，我希望能标记某个平台"暂停发布"，以便某些平台临时不更新时单独控制。 |
| P1 | 作为自媒体运营，我希望能看到每个平台上次发布内容的时间（从内容计划同步），以便发现长期未更新的平台。 |

### 4.3 颜色与下游联动

| 优先级 | 用户故事 |
|--------|---------|
| P0 | 作为自媒体运营，我希望能为每个账号分配一个颜色，以便内容计划看板卡片和今日工作台日历中用颜色区分账号。 |
| P0 | 作为自媒体运营，我希望内容计划页面的账号切换栏自动读取账号矩阵数据，以便新增账号后无需改代码即可选择。 |
| P0 | 作为自媒体运营，我希望停用账号后，内容计划的切换栏中不再显示该账号，以便只看到活跃账号。 |
| P1 | 作为自媒体运营，我希望能自定义账号颜色（从色板选择），以便按个人习惯区分账号。 |

**卡片展示内容**：

| 字段 | 来源 |
|------|------|
| 账号名称 + 颜色圆点 | OwnedAccount |
| 内容方向 | 如"美食·二人食晚餐" |
| 三平台状态 | ✓ 运营中 / — 暂停 / 未配置 |
| 运营状态标签 | 运营中 / 筹备中 / 已停用 |

**验收框架**：
- [ ] 账号卡片按网格排列，每张显示账号名称、颜色、方向、平台状态
- [ ] 空状态：无账号时显示"暂无账号，点击添加你的第一个账号"
- [ ] 停用的账号卡片置灰显示，与运营中账号区分

### 5.2 添加账号（Must-Have P0）

**触发**：账号矩阵页面 → "+ 添加账号"按钮 → 弹出表单。

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 账号名称 | 文本 | 是 | 如"苏师傅爱做饭" |
| 内容方向 | 文本 | 是 | 如"美食 / 二人食晚餐" |
| 运营状态 | 枚举 | 是 | 运营中 / 筹备中 / 已停用 |
| 颜色 | 色板选择 | 是 | 从预设色板选一个（默认自动分配） |
| 账号定位 | 文本 | 否 | 内容价值和表达方向 |
| 核心人群 | 文本 | 否 | 目标用户画像 |
| 核心 CTA | 文本 | 否 | 主要转化动作 |
| 备注 | 文本 | 否 | 补充说明 |

**三平台信息（可选填，可在详情中补充）**：

| 字段 | 说明 |
|------|------|
| 抖音用户名 + 主页链接 + 发布状态 | 默认"运营中" |
| 小红书用户名 + 主页链接 + 发布状态 | 默认"运营中" |
| 视频号用户名 + 主页链接 + 发布状态 | 默认"运营中" |

**验收框架**：
- [ ] 名称必填，未填时保存按钮置灰
- [ ] 名称重复时提示"该账号已存在"，不创建
- [ ] 颜色默认自动从色板分配，用户可改选
- [ ] 保存后新账号卡片出现在列表中，内容计划切换栏同步出现该账号
- [ ] 平台信息可不填，创建后到详情页补充

### 5.3 编辑 / 停用 / 删除账号（Must-Have P0）

**编辑**：点击账号卡片 → 详情页 → 编辑按钮 → 修改基本信息或平台信息。

**停用**：
- 停用后：内容计划切换栏不再显示该账号；今日工作台日历中该账号的历史发布记录颜色保留
- 历史内容卡片的账号标记不丢失（保留名称和颜色）

**删除**：
- 删除前弹窗二次确认："删除「xxx」将同时移除其发布记录，历史内容卡片将显示为'账号已删除'，确定删除？"
- 删除为软删除，数据保留 30 天可恢复（P1）

**验收框架**：
- [ ] 编辑后保存，列表和下游模块同步更新
- [ ] 停用后内容计划切换栏立即不显示该账号
- [ ] 停用不影响历史内容卡片的账号标记显示
- [ ] 删除需二次确认，取消不删除
- [ ] 删除后内容计划中该账号的卡片显示"账号已删除"标记

### 5.4 颜色管理（Must-Have P0）

**预设色板（9 色，与今日工作台日历共用）**：

| # | 颜色 | 说明 |
|---|------|------|
| 1 | #EF4444 红 | |
| 2 | #F97316 橙 | |
| 3 | #EAB308 黄 | |
| 4 | #22C55E 绿 | |
| 5 | #06B6D4 青 | |
| 6 | #3B82F6 蓝 | |
| 7 | #8B5CF6 紫 | |
| 8 | #EC4899 粉 | |
| 9 | #78716C 灰 | |

**分配规则**：
- 新账号创建时自动分配下一个未使用的颜色
- 用户可在编辑时手动从色板改选
- 已使用的颜色可以复用（两个账号同色会提示，但不禁止）

**账号×平台 → 今日工作台日历颜色**：
今日工作台日历中，每个"账号×平台"组合显示一个色块。规则：
- 主色 = 账号颜色
- 同一账号的三个平台用同色不同深浅（如抖音=实心、小红书=60% 透明度、视频号=40% 透明度）或同色加平台小图标区分

**验收框架**：
- [ ] 创建账号时颜色自动分配
- [ ] 编辑时可从 9 色色板改选
- [ ] 颜色变更后内容计划卡片标记和今日工作台日历同步更新

### 5.5 与内容计划联动（Must-Have P0）

- 内容计划"新建选题"表单的所属账号下拉 = 账号矩阵中"运营中 + 筹备中"的账号列表
- 内容计划顶部账号切换栏 = 同一数据源
- 卡片账号标记颜色 = 账号矩阵中该账号的颜色

**验收框架**：
- [ ] 账号矩阵新增账号 → 内容计划切换栏和新建表单下拉同步出现
- [ ] 账号矩阵停用账号 → 内容计划切换栏立即移除
- [ ] 账号颜色修改 → 内容计划卡片标记同步变色

### 5.6 与今日工作台联动（Must-Have P0）

- 今日工作台日历图例 = 账号矩阵账号列表（账号 × 平台）
- 日历颜色标记使用账号颜色体系

## 6. 数据模型

### 6.1 OwnedAccount 对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string (uuid) | 是 | 主键 |
| `space_id` | string | 是 | 所属选题空间 |
| `name` | string | 是 | 账号名称，如"苏师傅爱做饭" |
| `direction` | string | 是 | 内容方向，如"美食 / 二人食晚餐" |
| `status` | enum | 是 | `active` 运营中 / `preparing` 筹备中 / `paused` 已停用 / `deleted` 已删除 |
| `color` | string (hex) | 是 | 账号颜色，如 `#F97316` |
| `positioning` | string? | 否 | 账号定位 |
| `target_audience` | string? | 否 | 核心人群 |
| `cta` | string? | 否 | 核心转化动作 |
| `notes` | string? | 否 | 备注 |
| `created_at` | ISO 8601 | 是 | 创建时间 |
| `updated_at` | ISO 8601 | 是 | 更新时间 |
| `deleted_at` | ISO 8601? | 否 | 软删除时间 |

### 6.2 PlatformAccount 对象（嵌入 OwnedAccount）

每个 OwnedAccount 包含三个 PlatformAccount（每个平台一个）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `platform` | enum | `douyin` / `xiaohongshu` / `shipinhao` |
| `username` | string? | 平台用户名 |
| `profile_url` | string? | 平台主页链接 |
| `publish_status` | enum | `active` 发布中 / `paused` 暂停发布 / `unconfigured` 未配置 |

### 6.3 与下游模块的关联

```
OwnedAccount (账号矩阵)
  ├── ContentCard.account_id (内容计划) —— 卡片所属账号
  ├── 内容计划账号切换栏 —— 读取 active + preparing 的账号
  └── 今日工作台日历 —— 账号 × 平台 颜色标记
```

### 6.4 API 规划

| 方法 | 接口 | 作用 |
|------|------|------|
| GET | `/api/owned-accounts?space_id=X` | 账号列表（含平台信息） |
| POST | `/api/owned-accounts` | 创建账号 |
| PUT | `/api/owned-accounts/:id` | 更新基本信息 |
| PATCH | `/api/owned-accounts/:id/platform` | 更新某平台信息 |
| PATCH | `/api/owned-accounts/:id/status` | 变更运营状态 |
| DELETE | `/api/owned-accounts/:id` | 软删除 |

## 7. Success Metrics

| 指标 | 定义 | 目标 |
|------|------|------|
| 账号配置完成率 | 有平台信息的账号数 / 总账号数 | > 90% |

| 停用账号及时率 | 平台停更后 3 天内被标记停用的账号数 | 反映维护习惯 |
